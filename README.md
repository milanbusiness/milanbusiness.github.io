# MilanBusiness

Static GitHub Pages website for MilanBusiness exhibition accompaniment, interpretation, transfer coordination and business communication support in Milan.

## Files

- `index.html` - page structure and semantic content
- `styles.css` - responsive visual system
- `script.js` - language switching, carousel, quote summary and mailto inquiry flow
- `assets/milanbusiness-logo.svg` - scalable brand mark
- `sources.md` - event date and image source references

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static server.
